# Chris — 19th birthday site

A private birthday site for Chris. **Live:** https://tabsterwonkanogi.github.io/chris-birthday/

Vite + React + React Router. Mobile-first (most viewing is on a phone).
**Auto-deploys** to GitHub Pages on every push to `main` (see `.github/workflows/deploy.yml`).

## Pages

| Route | What it is |
| --- | --- |
| `/` | Landing — "Chrissy [Chris's face] Wissy" wordmark, nav, and the intro video below it |
| `/messages` | Swipeable card carousel; each friend's message shows below the bar |
| `/melodies` | Wall of record sleeves, each opening a real Spotify playlist |
| `/memories` | Photo mosaic, tap to enlarge (lightbox with swipe) |
| `/music` | "Jam with Friends!" — each row is a friend + the song they picked (opens in Spotify) |

## You only edit `src/data/`

- `messages.js` — one entry per friend. Fields: `name`, `text` (written, handwriting font),
  `audio` (`/audio/x.m4a`), `photo` (card cover `/photos/x.jpg`, optional `focus` crop anchor),
  `image` (a scanned card shown below the bar), `video` (`/video/x.mp4` + optional `poster`).
  A card can mix any of these.
- `photos.js` — the Memories mosaic. **Generated by `scripts/sync_photos.py`** — don't hand-edit;
  re-run the script after adding photos.
- `music.js` — the Jam with Friends rows (`name`, `song`, `artist`, `link`, `photo`) + header.
- `melodies.js` — the playlist sleeves (`title`, `url`, `disc` colour, `cover`).
- `landing.js` — wordmark, logo face, and the intro `video`. `nav.js` — the four nav links.

Style tokens are at the top of `src/styles/global.css` (forest `#0e1b14`, cream `#f0ecd9`,
orange `#e2622e`, Instrument Serif display, Space Mono body, Caveat for the handwritten
messages). **No em dashes in user-facing copy.**

## Adding media (needs a build environment — resize/transcode first)

- **Photos** → put images in the source `Images` folder, run `python scripts/sync_photos.py`,
  then commit. It optimises, shuffles, and rewrites `photos.js`. Skips videos.
- **Card photos / covers** → resize to ~800px, save as `public/photos/<name>.jpg`, set `photo`.
- **Audio** → convert to `.m4a` (mono AAC), save in `public/audio/`, set `audio`.
- **Video** → transcode to H.264/AAC mp4 (scale ≤1280, crf 23, `+faststart`), make a poster
  frame, save in `public/video/`, set `video` + `poster`.

## Run locally

```
npm --prefix chris-birthday run dev   # http://localhost:5179
npm --prefix chris-birthday run build # production build (set GITHUB_PAGES=1 for the /chris-birthday/ base)
```
